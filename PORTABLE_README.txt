Galgame UI 图片汉化工具 v0.7.0 绿色便携版

使用方法
1. 请先完整解压 ZIP，不要直接在压缩包内运行。
2. 双击 GalgameUiTranslator.exe。
3. 整个文件夹可以复制到其他 64 位 Windows 电脑使用，无需单独安装 .NET。

注意
- 不要只复制 EXE；旁边的 .runtime 文件夹是程序自带的运行环境。
- API Key 只保存在程序内存中，关闭软件后会清除。
- 翻译记忆、术语表和自动恢复文件保存在当前 Windows 用户的本地应用数据目录。
- 自定义文字样式预设也保存在当前 Windows 用户的本地应用数据目录，可跨工程使用。
- 图片列表提供缩略图和“未识别/待翻译/待校对/已校对”状态筛选。
- 批量任务与工程恢复点会自动保存；重启后打开工程，可在批量任务中心继续未完成项。
- 工具只处理已经解包的图片，不负责游戏资源的解包与回封。
